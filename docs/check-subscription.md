# 充值后怎么确认 Plus / Pro 到账了：会员不显示时的排查顺序

> 个人维护的第三方整理页，跟 OpenAI 没有官方关系。下面的处理办法一部分来自我自己的经历，一部分来自 [gptvip.pro](https://gptvip.pro) 常见问题里公开写的说明，具体权益以 ChatGPT 官方页面为准。

付完款最让人坐不住的，就是刷新了好几遍，左下角还是写着「免费版」。我第一次充的时候也慌过，后来发现绝大多数情况都不是没充上，而是页面还没刷新过来。下面按我自己的排查顺序写，从最省事的开始。

## 先确认你看的是不是同一个账号

听起来有点傻，但真有人在这里栽过：

- 电脑上登的是工作邮箱，充值时填的是私人邮箱；
- 用 Google 登录和用邮箱密码登录，生成的其实是两个不同的账号；
- 浏览器里同时开着两个 ChatGPT 账号，切来切去看错了。

所以第一步，先把订单里填的邮箱和你现在登录的邮箱对一下，一个字母都别差。

## 第一步：退出账号，重新登录

在 chatgpt.com 上完全退出登录，再重新登一次。手机 App 也一样，要退出重登，光把 App 划掉后台没用。

这一步能解决大部分问题。会员状态是登录时拉取的，旧的登录状态里还是老信息。

## 第二步：点一下「升级套餐」

重登之后还是免费版，就点页面左下角的「升级套餐 / Upgrade」，在弹出来的套餐页里看 Plus 那一栏：

- 如果显示「当前套餐」，或者已经不能再点订阅，说明会员其实已经到了，关掉弹窗回去聊天就行；
- 这个动作本身也会促使官方刷新一次你的会员状态。

注意只是点开看，别真的在这里再付一次钱。

## 第三步：等半小时左右再看

上面两步都做了还是不显示，多半是 OpenAI 那边同步慢了。gptvip.pro 给的建议是耐心等 30 分钟左右，再重新登录看一次。

这段时间别反复下单，也别急着换渠道再充，不然很容易变成两份订阅撞在一起，后面更难处理。

## 第四步：超过 30 分钟还没有，带着订单号找客服

这时候就别自己猜了，直接联系客服核查。提前准备好这几样，沟通会快很多：

- 订单号；
- 付款记录截图；
- 当前账号显示免费版的截图（把邮箱以外的隐私信息遮一下）。

gptvip.pro 的客服可以加微信或 QQ，网站写的在线时间是 9:00 到 22:00。下单之后也可以先去网站的订单查询页看看处理状态。

**不管谁问，都不要发密码、邮箱验证码、Cookie 或 Session Token。** 核查到账不需要这些。

## 到账以后，我会顺手核对的几件事

1. **有效期**：在设置里看下次续费或到期的日期。gptvip.pro 写的是如果到账后发现有效期不满一个月，会按缺的天数补差价，所以这个日期值得截个图留着。
2. **套餐名称**：确认是你买的那一档，Plus 和 Pro 别搞混。
3. **常用功能**：随手试一下文件上传、图片这些平时要用的能力。具体有哪些功能，以 ChatGPT 官方当前页面显示为准。
4. **安全设置**：顺便把二步验证打开，以后登录更安心。

## 几个容易误会的地方

**充了 Plus，API 能用了吗？**
不能。ChatGPT 会员和 OpenAI 的 API 是两套计费，API 要去开发者平台单独充值。

**手机上显示了，电脑上没显示？**
一般是电脑这边还挂着旧的登录状态，按第一步退出重登就好，反过来也一样。

**到账后能退吗？**
按 gptvip.pro 写的规则，充值不成功的订单当天退款；一旦充值成功就不支持退款。所以下单前把账号和套餐确认好，比事后折腾省心得多。
