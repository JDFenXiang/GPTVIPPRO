# ChatGPT Plus 和 Pro 怎么选：充值前对照官方差异和平台套餐

> 个人维护的第三方整理页，跟 OpenAI 没有官方关系。下面分开写两块：一块是我在 OpenAI 公开定价页和帮助中心里核对过的套餐差异，一块是 [gptvip.pro](https://gptvip.pro) 价格页、充值教程和常见问题里公开写的说明。ChatGPT 里实际能用什么，以你账号里的官方页面为准；平台价格和售后规则，以 gptvip.pro 当时显示的为准。

付款之前最容易卡住的，往往不是支付宝扫不扫得了码，而是 Plus 和 Pro 到底差在哪。两档名字都看着「高级」，价差又不小，很容易下意识觉得贵的一定更值。我对照官方页面之后，更愿意这么理解：Plus 先解决日常够不够用，Pro 再解决额度、上下文，以及一部分开发者相关的权益。

## 先说我自己的选法

- 平时就是写作、翻译、读文件、出图，偶尔用一下 Codex：先看 Plus。
- 经常碰到额度上限，需要更长的 Codex 或「ChatGPT 工作」会话，想用官方说的 Pro 推理，或者希望按官方规则领取 API 额度：再考虑 Pro。
- 别只盯着「5 倍 / 10 倍 / 20 倍」这种名字下单。OpenAI 官方现在把个人 Pro 写成 Pro 100、Pro 200、Pro 500 三档；gptvip.pro 价格页上的商品名是 Pro（10x）、Pro（20x）。这是两套叫法，我没法在这里帮你一一对应，下单前以商品详情和客服确认为准。
- 账号里已经是 Plus、想改成 Pro：先问客服。网站把这种情况归到「订阅冲突」，直接再下一单不一定合适。

## OpenAI 官方现在怎么区分这两档

这一节只写我核对过的公开信息，不把它说成 gptvip.pro 的承诺。主要来源是 [ChatGPT 套餐和价格](https://chatgpt.com/zh-Hans-CN/pricing/)、[什么是 ChatGPT Plus？](https://help.openai.com/zh-hans-cn/articles/6950777-what-is-chatgpt-plus)、[关于 ChatGPT Pro 套餐档位](https://help.openai.com/zh-hans-cn/articles/9793128-about-chatgpt-pro-tiers)，以及 [ChatGPT 订阅用户的 API 额度说明](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)。模型名称、开放范围和限额都会变，最终仍以你账号里的模型选择器为准。

### 官方标价

帮助中心写明：ChatGPT Plus 是每月 20 美元，按月结算；目前不支持官方的年度结算，也不支持一次预付多个月。

Pro 目前是三档月付：Pro 100 为每月 100 美元，Pro 200 为每月 200 美元，Pro 500 为每月 500 美元。帮助中心同样写明，Pro 按月计费，暂不支持官方年付或一次预付多个月。超快模式（页面上也叫极速模式）只写在 Pro 500 这一档里。

这些都是官方美元标价。国内代充页面上的人民币价格，是平台自己的商品定价，不能直接当成 OpenAI 官网收款价。

### Plus 大概能解决什么

按帮助中心和定价页的说法，Plus 相对免费版会有更高的模型限额、高峰时段更优先的访问，以及更快的回复。定价页还给 Plus 写了这些方向：

- 包括 GPT-6 在内的高级推理模型；
- 更高的消息和上传配额；
- 更复杂、更精确的图像生成；
- 增强的深度研究；
- 更强的记忆和上下文；
- 项目、计划任务和自定义 GPT；
- 更高的 Codex 使用量；
- 在桌面端、网页端和移动端使用「ChatGPT 工作」时，权限比免费档更高；
- 可以更早体验部分新功能。

帮助中心同时写得很清楚：Plus 不包含计入 OpenAI 开发者平台账单的 API 用量。ChatGPT 会员和 API 是两套计费，这个区别后面还会再提一次。

Plus 也不是无限用。官方说它在高峰期可能有消息上限，具体限制会随系统状况变化，没有对外写死「每天能问多少句」。

### Pro 在 Plus 之上，官方多写了什么

中文定价页把 Pro 概括成更适合研究和编程，并在 Plus 的基础上加了这些描述：

- 可以在 3 个用量档位里选择；
- 由 GPT-6 Astra 驱动的 Pro 推理；
- 更长的 Codex 和「ChatGPT 工作」会话；
- dot（官方写成全天候智能体；对比表里 Plus 为否，Pro 为是）；
- 更快、且页面写成「无限量」的图像创作；
- 最高档的深度研究、记忆和上下文；
- 更多的项目、任务和自定义 GPT；
- 新功能的研究预览；
- 符合条件时，每月可领取用于开发者平台的 API 额度。

定价页对「无限」加了脚注：使用须合理，并遵守政策。Pro 档位说明里也写了，所有写成无限的权益都受防滥用机制约束。所以看到「无限」两个字，别理解成绝对没有上限。

### 上下文长度：这是少数能核对到数字的差别

官方对比表里，有几项写出了明确数字，我照录如下。页面同时说明，用户真正能输入的篇幅会小于窗口总量，因为系统指令、记忆和内部处理也要占空间；标出来的页数是近似值。

- GPT 推理总上下文窗口：Plus 为 256K，Pro 为 400K；
- GPT 推理输入上限：Plus 约 320 页文本，Pro 约 680 页文本；
- GPT Instant 输入上限：Plus 约 40 页文本，Pro 约 250 页文本。

如果你经常要把很长的材料或比较大的代码上下文一次丢进去，这一项比「名字听起来更高级」更有参考价值。

### 模型权限不要记成固定名单

定价页的对比表还写了不少模型名，比如 GPT-6.1 Sol、GPT-6 Astra、GPT-6 Sol 在 Plus 上多为「有限」，在 Pro 上多为「扩展版」。GPT-5.6 Sol Pro 这一项，我看到的表格把「无限制」（同样带防滥用注释）写在了 Pro 上。

这些名字和开放范围变动很快，我不在这里把整张表抄一遍，免得过两周就过时。你真正该看的，是自己账号里当时能选到哪些模型，以及用到上限时页面提示什么时候重置。

### Codex 两档都有，差别主要在用量和会话长度

定价页给 Plus 写的是「更高的 Codex 使用量」，给 Pro 写的是「更长的 Codex 和 ChatGPT 工作会话」。也就是说，不是只有 Pro 才能碰 Codex；Plus 同样包含 Codex，只是用量和会话长度不是同一档。

官方没有把 Codex 写成一个固定次数。Pro 档位说明里还提到：能完成多少工作，仍然取决于模型、任务和设置，更多用量并不保证能做完两倍数量的任务。

### API 额度：这是 Plus 和 Pro 很实在的一条分界

帮助中心写明，Plus 的 API 使用量要单独计算、独立计费。开发者文档则写：符合条件的 ChatGPT Pro 和 Business 订阅，可以把订阅关联到自己拥有的 API 组织，按月领取 API 额度。

文档里目前写的对应关系是：Pro 100 对应每月 100 美元额度，Pro 200 对应 200 美元，Pro 500 对应 500 美元。领取时还有几条不能省略的条件：订阅一般要已生效至少 7 天，试用或赠送订阅不算；你得是该 ChatGPT 订阅和目标 API 组织的所有者；两边要用同一个邮箱。额度不会自动滚到下个账期，首次发放还会按当前周期剩余时间折算。

另外，这份 API 额度不会增加你在 ChatGPT 或已登录 Codex 里的用量，也不覆盖用 API Key 去调用 Codex 的那部分消耗。所以即便开了 Pro，也不等于「聊天额度用完了，可以拿 API 额度继续在 ChatGPT 里聊」。

降到 Plus、Go 或免费版时，官方写的是：账期结束后会解除和 API 组织的关联。一句话总结：Plus 不要指望附带开发者平台额度；Pro 有这个方向的官方权益，但要自己开通，且受资格限制。

## 几种常见情况，我会怎么选

主要是日常对话、写材料、翻译、读 PDF、偶尔生成图片：选 Plus 月费通常就够了。官方给 Plus 已经写了更高的消息和上传配额，也包含 Codex，只是用量不是最高档。

一周只会抓紧写几次代码，并不会整天挂着 Codex：我还是会先试 Plus。如果用了一段时间后频繁看到额度用完的提示，再考虑 Pro，比一上来就买最高档稳妥。

每天都在用 Codex 或「ChatGPT 工作」，或者经常要把很长的材料一次丢进去：这时官方写的「更长会话」和更大的推理上下文，对 Pro 更有利。至于选平台上的 10x 还是 20x，我建议直接问客服你的账号适合哪一档，不要只根据倍率名字自行换算。

自己平时也在开发者平台调 API，希望用上官方说的订阅附带额度：这条权益写在符合条件的 Pro（以及 Business）上，Plus 没有。记得它要单独开通，也不会增加 ChatGPT 里的对话次数。

公司报销需要发票：平台写明可以开普票，另收手续费，下单后当天找客服说。Plus 或 Pro 都能走这套售后，开票本身不能当成「必须买 Pro」的理由。

## 下单前我会再确认一遍的事

1. 账号能正常登录，状态没有明显异常。网站写的是：账号存在异常、地区限制或订阅冲突时，最好先联系客服。
2. 看清楚自己要的是 Plus 还是 Pro，以及价格页上那一档的准确商品名。
3. 用真实能联系到的邮箱下单，方便查订单。
4. 不要把 ChatGPT 密码、邮箱验证码交给任何人。
5. 充好之后，自己登录账号看会员状态和到期时间。如果页面还显示免费版，可以按这篇的顺序排查：[充值后怎么确认 Plus / Pro 到账了](check-subscription.md)。
